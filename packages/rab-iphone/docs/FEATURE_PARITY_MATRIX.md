## Legend

### State

Each row has exactly one state.

| Code | Meaning |
|---|---|
| **V** | Implemented & contract verified. The Flutter feature is committed and its server contract was read and matched field by field. The backend is live on dev per HANDOFF, or no backend is needed. |
| **R** | Implemented in source, runtime not verified. The code exists, but the server side is not deployed to dev, not configured, or not device-verified. |
| **C** | Being changed by another session. The Flutter file and/or the server contract is in the uncommitted working tree. Re-check it before porting. The Dependency column gives the deploy status. |
| **A** | Approved requirement, backend not available. |
| **N** | Not part of the mobile app. It is web-only, or a server route exists that Flutter does not use. |

### Swift column

Filled per row. Every Swift cell is source only: nothing has been compiled or run (Windows host).
