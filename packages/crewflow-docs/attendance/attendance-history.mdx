| Who | Where | What they see |
| --- | --- | --- |
| **Staff** | Mobile app → **History** | Each completed shift: venue, role, earnings, status, scheduled times and actual times with hours worked. |
| **Venue managers** | Mobile app → **History** and **Reports** | Past events and confirmed staffing, and each shift's attendance report. |
| **Managers** | Web console → **Payroll** | Every attendance record with hours and calculated pay. |
| **Managers** | Web console → **Audit Log** | Clock-ins, clock-outs, corrections and finalisations. |

Each card shows "Scheduled 17:00–23:00" and "Actual 16:52–23:04 · 5h 42m worked", for example. An empty history reads "No history yet — Completed shifts will show up here."

## Attendance statuses

| Status | Meaning |
| --- | --- |
| Not clocked in | Scheduled; no clock-in yet. |
| Clocked in | On shift. |
| Clocked out | Finished; awaiting review. |
| Under review | Corrected, or flagged for checking. |
| Approved | Finalised on the timesheet. |
| Missing clock-out | Did not clock out. |
| Late | Clocked in late. |
| Absent | Did not attend. |
| Disputed | Under discussion. |
