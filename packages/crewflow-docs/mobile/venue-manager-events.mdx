## Calendar

The **Calendar** tab works like the staff calendar, with **Today** and **Month** views, but lists your venues' events. Each shows its status:

| Status | Meaning |
| --- | --- |
| **Awaiting approval** | Your request is waiting for a manager. |
| **Open request** / **Offers sent** | Approved; offers are out. |
| **Partially filled** / **Filled** | Some or all places are taken. |
| **Confirmed** | The team is confirmed. |
| **Live** | The event is under way. |
| **Complete** | Finished. |
| **Declined** / **Cancelled** | Not going ahead. |

"No scheduled events" means nothing is planned in the period.

## Event Details

Tap an event to open **Event Details**:

- **Staffing** — **Required**, **Confirmed** and **Open positions**
- **Confirmed staff** — who is coming
- **NOTE** — instructions for the event

**Send offers** appears only if your account is allowed to send offers, you created the shift, and there are places left. "Staff acceptance still requires Manager confirmation."

## History

The **History** tab lists past events and their confirmed staffing. "No historical activity yet." means there is nothing to show.
