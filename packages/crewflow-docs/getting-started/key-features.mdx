## Everything included today

| Area | Highlights |
| --- | --- |
| **Accounts** | Email invitations, password sign-in, optional Google and Microsoft sign-in, password reset, active-session management, and fingerprint or face unlock in the mobile app. |
| **Organisation** | Private manager workspaces, member invitations, custom roles, and platform administration for organisations. |
| **Staff** | Four-step staff creation, automatic staff references, invitation tracking, editing, deactivation and bulk email. |
| **Venues** | Address, client, type, map location with an optional geofence, default break, and role-specific pay rates. |
| **Shifts** | Create and send in one step, publish drafts, cancel with a reason, and approve venue manager requests. |
| **Offers** | Bulk offers, per-batch "Confirm All Accepted", automatic expiry, replacement suggestions and a live staffing board. |
| **Attendance** | QR clock-in and clock-out, optional geofence, late and no-show detection, missing clock-out detection, and corrections with a recorded reason. |
| **Timesheets** | A roster PDF with the shift QR code before each shift, venue manager review and finalisation, and final timesheet PDFs. |
| **Pay** | Calculated hours and pay from attendance, using the rate locked in when the offer was sent. |
| **Oversight** | Audit log of sensitive actions, in-app notifications and email delivery. |

Some features are still being built. [Product status](/getting-started/product-status) lists them honestly.
