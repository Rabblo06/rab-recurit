## Tabs

| Tab | Contains |
| --- | --- |
| **Overview** | Contact details, key information, personal details, address, and — under **Show more details** — emergency contact and availability. |
| **Timeline** | A history of the account, such as "Account created" and "Invitation sent". |
| **Email** | Emails sent to this person from Crewflow. |
| **Notes** | Private notes from managers. Select **+ New note**, write it and **Save note**. |

## Edit details

Hover over a field and select the pencil. Changes save when you leave the field.

**Key Information** holds the **Staff reference** (read-only), **Job role**, **Employment type**, **Start date**, **Default rate** and **Status**. Changing the default rate does not change offers already sent: each offer keeps the rate it was sent with.

## Employment status

Employment status records whether the person can currently be offered work:

| Status | Meaning |
| --- | --- |
| **pending compliance** | Created and awaiting checks. |
| **active** | Can be offered work. |
| **inactive** | Not currently working. |
| **suspended** | Temporarily barred. |

Changes follow the allowed paths — for example, suspended staff can go back to active or to inactive.

## Actions

From **More actions** at the bottom of the panel:

| Account state | Actions |
| --- | --- |
| Invited | **Resend invitation** / **Re-invite**, **Cancel invitation**, **Delete user** |
| Active | **Reset password**, **Deactivate** / **Reactivate**, **Delete user** |

**Reset password** asks you to confirm — "They'll be emailed a new one-time setup link." — and signs them out everywhere. **Send Email** writes to just this person.
