# Creating a venue

Every shift belongs to a venue. This tutorial shows how to add one, using fictional demonstration data.

On Venues, select New venue.

Enter the venue name, the client and the venue type.

Add the address.

Set the location and the geofence radius. Staff must be inside this area to clock in when the geofence is enforced.

Set the default break in minutes.

Select Create venue. The drawer stays open so you can add pay rates.

Add an hourly rate for a role at this venue, then select Save changes.

The new venue appears in the list.
