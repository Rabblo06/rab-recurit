Crewflow tutorial

Adding sidebar shortcuts

Operations, Add menu item

Add menu item
Your shortcut

You can add your own shortcuts to the sidebar. This tutorial uses fictional

demonstration data.

Select the plus beside Operations to open Add menu item.

A shortcut can be an Object, which is a Crewflow page, a filtered View, a Record,

a Folder, or a Link.

Choose View, and pick a filtered list.

Give the shortcut a name and an icon, then select Add.

The shortcut appears under Operations. Opening it goes through the normal page,

so your usual access still applies.

Use the options button on a shortcut to rename or remove it. Shortcuts are saved

on this device, for your account and workspace.
