# Assigning staff to a venue manager

A venue manager can only see and select the staff you assign to them. This tutorial shows how to assign a team, using fictional demonstration data.

Open Users, then select the Venue managers tab.

Select View on a venue manager to open their details.

Open the More menu beside the tabs, and choose Assigned staff.

This list is everyone the venue manager can currently see and select in their app.

Select Add Staff. The Select Staff page lists the staff in your workspace, and anyone already assigned is marked Assigned.

Tick the people you want to add, then select Confirm.

They now appear in the assigned list. To remove someone, select the cross beside their name and confirm. Their account and work history are not deleted.
