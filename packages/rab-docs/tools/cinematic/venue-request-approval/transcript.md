# Approving a venue request

Venue managers send staffing requests from the mobile app. When you approve a request, Crewflow sends an offer to each person you selected. This tutorial uses fictional demonstration data.

Open Venue Offers in the sidebar. Requests waiting for you show Pending approval.

Open the pending request. The drawer shows the venue, role, times, and the staff the venue manager chose.

Here, two places are still open, so select staff to fill them.

On the Select Staff page, tick the people you want, then select Confirm.

With every place filled, select Approve.

The staffing board opens, with the new offers in the Offered lane. Each staff member still needs to accept their offer.
