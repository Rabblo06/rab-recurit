# Creating a shift and sending offers

This tutorial shows how to create a shift and offer it to staff in one step, using fictional demonstration data.

On Shifts, select New shift.

Choose the venue and the role. The address fills in from the venue.

Set the date, the start and end times, and the break.

Select staff to open the Select Staff page. Tick the people to offer the shift to, then select Confirm.

Select Send Offer. Crewflow creates the shift and sends an offer to each person.

The result lists every offer that was sent, and explains any person who could not be offered the shift.
