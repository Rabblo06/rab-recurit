## In development

| Feature | Current state |
| --- | --- |
| **Push notifications** | The delivery pipeline and the Android client are built but not yet verified on devices. Today, rely on in-app notifications and email. |
| **iOS app** | Not available yet. The mobile app currently runs on Android only. |
| **Real-time updates** | Built and switched off by default. When it is off, pages refresh on a timer instead. |
| **Per-workspace database schemas** | Built behind a setting and not yet switched on. This does not change how you use Crewflow. |
| **Workspace sign-in pages by web address** | Each workspace has its own address, but signing in currently uses the main sign-in page for everyone. |

## Planned or not supported

| Feature | Status |
| --- | --- |
| **Payroll approval and payment processing** | Planned. Crewflow calculates pay but does not approve pay runs, mark pay as paid or send money. |
| **Payslips** | Not available. The Payslip item in the staff app is disabled. |
| **Paid breaks** | A venue can be marked "Paid" for breaks, but pay calculations currently always deduct the break. Treat breaks as unpaid. |
| **Break start and stop in the app** | Not available. Worked time uses the scheduled break length. |
| **Drawn signatures on timesheets** | Not available. When finalising, the venue manager confirms their name, and the name and time are printed on the final timesheet. |
| **Timesheet and payroll export to CSV** | Not available. Timesheets are available as PDFs. |
| **Decline reasons in the staff app** | Staff decline without a reason. A reason can only be given by managers when rejecting. |
| **Switching between workspaces** | Not supported. Each account works in one workspace. |
| **Venue managers choosing their own team** | Not available. A manager assigns each venue manager's team in the web console. |
| **Calendar day and week views, drag to reschedule** | Not available. The calendar shows one month at a time. |
| **Staff availability editing in the app** | Not available. Availability is set by a manager on the staff record. |
| **AI assistant** | The chat screen and **Ask AI** panel exist, but no AI service is connected and sending is disabled. |
| **Shortcuts on every device** | Not available. Sidebar shortcuts are saved on the device where you add them. |
