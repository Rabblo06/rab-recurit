Open **Settings**, or select your workspace name at the top of the sidebar and choose **Workspace settings**. The **Workspace** section has **General**, **Domains** and **Members**.

## General

<Frame caption="Settings → Workspace → General.">
  <img src="/images/web/settings/my-workspace-general.webp" alt="Workspace General settings with picture, name and workspace URL" />
</Frame>

| Field | What you can do |
| --- | --- |
| **Picture** | **Upload** or **Remove** the workspace logo. |
| **Name** | Change it and select **Save changes**. |
| **Workspace URL** | Shows the workspace's web address. Change it on **Domains**. |

If you see "No private workspace", your account does not own a workspace — for example, a workspace member invited by a manager. Managers and CEOs each have their own workspace.

## Domains

<Frame caption="Settings → Workspace → Domains.">
  <img src="/images/web/settings/my-workspace-domains.webp" alt="Workspace Domains page with the subdomain and Copy URL" />
</Frame>

Select the pencil (**Edit subdomain**) next to the subdomain to change it. Crewflow shows *Checking availability…* as you type, then either *✓ name is available* or a reason it can't be used ("This subdomain is already taken." or "This subdomain cannot be used."), with suggestions you can pick. Select **Save** to apply it or **Cancel** to keep the current address. **Copy URL** copies the full address (the button briefly reads **Copied**).

<Note>
  Each workspace has its own address, but signing in currently uses the same Crewflow sign-in page for everyone. Workspace-branded sign-in pages are in development.
</Note>
