These tasks are only available to **platform administrators**, in **Settings → Admin Panel**. The panel has four tabs: **General**, **Organisations**, **Config** and **Health**.

## Create an organisation

<Steps>
  <Step title="Select + New Organisation">
    On the **Organisations** tab. The **New Organisation** drawer opens: *Creates the organisation and invites its first CEO.*
  </Step>
  <Step title="Enter the details">
    **Organisation name**, **CEO email**, **CEO first name** and **CEO last name**.
  </Step>
  <Step title="Create">
    Select **Create Organisation & Invite CEO**, then **Done**. Crewflow creates the organisation and sends the CEO invitation in one step.
  </Step>
</Steps>

Find an organisation with **Search by name or CEO…**, or narrow the list with the status filter (**All statuses**, **Active**, **Invited**, **Invite expired**, **Organisation suspended**).

### The CEO invitation

Open an organisation to manage its CEO invitation:

- **Resend invitation** — sends the link again (up to three sends). After an invitation expires or is cancelled the button reads **Re-invite**.
- **Revoke invitation** — stops the link working; confirm or choose **Back**.

Only platform administrators can create or change CEO accounts.

<Note>
  An organisation's **Initial Manager** is managed by that organisation's CEO in **Settings → Members → Add**. Platform administrators can't invite or replace another organisation's Initial Manager.
</Note>

## The General tab

**About** shows the **Current version** and **Latest version** of Crewflow. **Recent Users** lists recently added accounts; search with **Search by name or email…**.

## Configure the service

On the **Config** tab:

- **SMTP settings** — **SMTP Host**, **SMTP Port**, **Encryption**, **SMTP Username**, **SMTP Password**, **From Name** and **From Email**. Save with **Save changes**, and check the server with **Test SMTP Connection** and **Send Test Email**.

  <Warning>
    Crewflow currently sends its emails using the email settings configured on the server when it was deployed, not the SMTP settings saved here. A successful test on this tab confirms that mail server works; it does not change how invitations and timesheets are delivered. See [Email and notifications](/developers/email-and-notifications).
  </Warning>

- **Storage** — the **Storage provider** where files such as photos and timesheet PDFs are kept.
- **Maintenance mode** — switch between **Enabled** and **Disabled**, set the **Message shown to users**, then **Save changes**. While it is on, ordinary use is blocked while work is carried out.

The **Health** tab reports Database, API, Storage, Redis and Worker as Operational, Degraded, Down or Unknown. Select **Refresh** to check again.

## Suspend or reactivate an organisation

Crewflow can suspend a whole organisation, for example when a contract is paused. Suspending is reversible and never deletes data.

<Note>
  There is no suspend button in the Admin Panel yet. Suspension is carried out by the Crewflow operations team through the administration API, which requires the administrator's current password and the organisation's short name as confirmation. See [API endpoints](/developers/api-reference/endpoints#platform-administration).
</Note>

| While suspended | Effect |
| --- | --- |
| Sign-in | Everyone in the organisation is signed out and cannot sign in. |
| Invitations | New invitations cannot be sent or accepted. |
| Notifications | No notifications or emails are sent to the organisation. |
| Data | Nothing is deleted. Background record-keeping continues so the history stays accurate. |

Reactivating lets people sign in again. Sessions that existed before the suspension stay ended, so everyone signs in afresh.

<Note>
  Platform administrators can still sign in while an organisation is suspended, so they can investigate and reactivate it.
</Note>
